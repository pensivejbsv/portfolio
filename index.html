2과목 기획 함정과 방법론 구성을 앞당긴 ADsP 학습 동선

이번 일일 스냅샷은 새 질의내역 두 개가 2과목에서 반복된 혼동을 가리켰기 때문에, What·How 4분면과 분석방법론 4구성요소를 기존보다 앞단으로 당겼다. 약어는 원어와 존재 이유를 함께 붙이고, 저장소 구분은 DW·DM·OLTP·OLAP처럼 범위와 역할 차이로 설명한다.

01 · DATA → DIKW

DIKW와 데이터 정의를 먼저 고정

DIKW(Data, Information, Knowledge, Wisdom)는 가공 전 사실이 왜 의사결정 가능한 지혜로 바뀌는지 설명하려고 존재한다. 정반비와 공표연내(SECI)를 붙여 1과목 정의형 함정을 먼저 막는다.

  • 정반비 = 정형 / 반정형 / 비정형
  • 공표연내 = 공통화 / 표출화 / 연결화 / 내면화
  • 정보와 지식의 차이를 문장으로 판별
02 · DB / SQL

DBMS와 SQL 명령 체계를 역할별로 분리

DBMS(Database Management System), RDBMS, NoSQL, 스키마, 메타데이터, DDL·DML·DCL·TCL은 저장, 구조 정의, 조작, 권한 제어를 분리하기 위해 등장했다. 공통저변과 개논물을 함께 붙여 설계 절차까지 복기한다.

  • 공통저변 = 공용 / 통합 / 저장 / 변화
  • 개논물 = 개념 / 논리 / 물리 설계
  • RDBMS와 NoSQL을 범위·구조로 구분
03 · DW / BIG DATA

저장소 흐름과 빅데이터 전환 이유를 한 장에 묶기

OLTP·ERP·CRM·SCM·KMS에서 나온 운영 데이터는 ODS(Operational Data Store), ETL(Extract, Transform, Load), DW(Data Warehouse), DM(Data Mart), OLAP, BI, BA로 이어진다. 동시에 3V·5V와 전후양상으로 왜 기존 처리 방식이 바뀌었는지 같이 본다.

  • DW = 전사 통합 분석 창고
  • DM = 특정 부서·업무용 분석 매장
  • 전후양상 = 전수조사 / 후처리 / 양 / 상관관계
04 · PLANNING TYPES

What·How 축으로 과제 유형 4분면 고정

Optimization, Solution, Insight, Discovery는 분석 대상 What과 분석 방법 How 중 무엇이 불명확한지 구분하려고 만든 4유형이다. 최근 질의내역에서 가장 많이 흔들린 지점이라 계산 단계보다 먼저 배치했다.

  • 다 알면 최적화
  • 문제만 알면 솔루션
  • 방법만 알면 인사이트
05 · METHODOLOGY

KDD·CRISP-DM과 방법론 4구성요소를 한 묶음으로 암기

KDD와 CRISP-DM은 모델 이름이 아니라 프로젝트를 관리하는 방법론이다. 절차·방법·도구와 기법·템플릿과 산출물은 최근 질의내역에서 순서-할 일-쓸 것-남길 것으로 다시 정리된 핵심 프레임이다.

  • KDD = 선택 / 전처리 / 변환 / 마이닝 / 평가
  • CRISP-DM = 업무이해 / 데이터이해 / 준비 / 모델링 / 평가 / 전개
  • 4구성요소 = 순서 / 할 일 / 쓸 것 / 남길 것
06 · GOVERNANCE

과제중심 접근과 마스터플랜 접근을 조직 구조와 연결

과제중심 접근은 지금 풀 문제를 빠르게 해결하기 위한 방식이고, 마스터플랜 접근은 전사 데이터 활용 체계를 설계하기 위한 방식이다. 하향식·상향식 접근, 도준정확, 집중·기능·분산 구조를 비교형 보기 기준으로 묶는다.

  • 도준정확 = 도입 / 준비 / 정착 / 확산
  • 집기분 = 집중 / 기능 / 분산
  • 목적·1차 목표·과제유형·접근방식 비교
07 · PREP / DM

DW·DM 범위 차이 위에 전처리 기준 올리기

저장소 범위를 먼저 구분한 뒤 EDA, 결측값, 이상값, 요약변수, 파생변수, 데이터마트 준비 순서를 올린다. 저장소 정의와 전처리 절차를 한꺼번에 뒤섞어 틀리는 패턴을 줄이기 위한 단계다.

  • EDA = 보기 전 데이터 상태 파악
  • 이상값 = ESD / IQR / Z-Score 비교
  • DM은 특정 분석 주제용 축소 저장소
08 · CALCULATION

공식보다 분자·분모와 해석 축부터 떠올리기

기댓값, 분산, 신뢰구간, p-value, 오분류표, 지지도·신뢰도·향상도는 공식 자체보다 어떤 기준 축을 쓰는지가 더 중요하다. 계산형과 보기형 함정을 동시에 줄이는 손풀이 루프다.

  • 오분류표 = 실제값 기준으로 재현율·특이도 판별
  • 향상도 1 초과 = 양의 연관
  • 표준오차는 표준편차와 별도 개념
09 · MODEL / REVIEW

모델 비교 후 다시 정의·기획 카드로 되돌아가기

회귀, 분류, 군집, 연관, 시계열, 차원축소 모델의 단서를 비교하고, 틀린 문항은 DIKW, 저장소, 기획 유형, 방법론 카드로 되돌아가 복구한다. 모델 이름만 외우는 공부보다 연결 약한 지점을 찾는 회독에 가깝다.

  • CART / C4.5 / CHAID 차이
  • K-means / DBSCAN 비교
  • 오답은 앞단계 정의 카드로 역추적

[기초] 군집분석은 정답 라벨이 없는 데이터들을 유사성이나 거리 기준으로 묶는 비지도학습 방법이다. K-means는 군집 수 K를 먼저 정하고 중심점을 반복 갱신하면서 군집을 나눈다. 계층적 군집은 가까운 개체나 군집을 단계적으로 합치거나 나누면서 덴드로그램으로 구조를 보여준다. DBSCAN은 밀도가 높은 구역을 하나의 군집으로 보고, 주변 밀도가 낮은 점은 노이즈로 처리한다.

[심화] K-means는 초기 중심점과 이상치에 민감하고 보통 Elbow Method나 WCSS를 통해 적절한 K를 고른다. 계층적 군집은 단일연결, 완전연결, 평균연결, 와드 연결처럼 군집 간 거리 정의가 다르며 덴드로그램 절단 높이에 따라 군집 수가 달라진다. DBSCAN은 Eps와 MinPts를 미리 정하지만 군집 수를 사전에 정하지 않아도 되고, 비구형 군집과 노이즈 처리에 강하다는 장점이 있다. 다만 밀도 차이가 큰 데이터에서는 파라미터 설정이 까다로울 수 있다는 점도 함께 기억해야 한다.

[공부 순서] 1단계 K-means의 K 지정과 중심점 갱신 절차를 암기한다. 2단계 계층적 군집의 덴드로그램과 연결법 종류를 구분한다. 3단계 DBSCAN의 Eps·MinPts·노이즈 개념을 정리한다. 4단계 보기 문장에서 중심점, 덴드로그램, 밀도라는 단어를 단서로 알고리즘을 즉시 매칭하는 연습으로 마무리한다.

[기초] 연관분석은 여러 품목이 함께 나타나는 패턴을 규칙 형태로 찾는 방법이다. 가장 기본 규칙은 A이면 B가 함께 나온다는 A → B 형태다. 지지도는 전체 거래 중 A와 B가 동시에 나온 비율이고, 신뢰도는 A가 나온 거래 중 B도 함께 나온 비율이며, 향상도는 A와 B의 동시출현이 우연보다 얼마나 강한지를 보여주는 비율이다.

[예상 문제] 시험에서는 전체 거래 수, A 구매 수, B 구매 수, A와 B 동시 구매 수를 주고 세 지표를 계산하게 하거나, 향상도 1을 기준으로 양의 연관·독립·음의 연관을 구분하게 만든다. 지지도는 전체 분모, 신뢰도는 조건부확률, 향상도는 신뢰도 ÷ B의 단순 구매확률이라는 흐름이 흔들리면 보기형 함정에 걸리기 쉽다.

[심화] Apriori는 최소 지지도를 만족하는 빈발항목집합만 확장하면서 후보를 줄이는 알고리즘이고, FP-Growth는 반복 후보 생성 부담을 줄이기 위해 트리 구조를 활용한다. ADsP에서는 복잡한 구현보다 Apriori가 계산량이 커질 수 있다는 점, FP-Growth가 이를 개선한 방법이라는 비교가 더 자주 출제된다. 향상도가 1보다 크면 양의 상관관계, 1이면 독립, 1보다 작으면 음의 상관관계라는 해석도 정리해야 한다.

[공부 순서] 1단계로 지지도·신뢰도·향상도 공식을 한 줄씩 암기하고, 2단계로 장바구니 표에서 분모가 무엇인지 먼저 표시한다. 3단계로 향상도 해석을 1 기준으로 구분하고, 4단계로 Apriori와 FP-Growth 차이를 비교형 문장으로 직접 써보며 마무리한다.

[기초] 과대적합은 모델이 학습데이터를 지나치게 세밀하게 따라가서 훈련 성능은 높지만 새로운 데이터에서 성능이 떨어지는 상태다. 보통 분산이 높고 편향이 낮은 쪽과 연결된다. 반대로 과소적합은 모델이 지나치게 단순해 데이터 구조를 충분히 설명하지 못하는 상태로, 편향은 높고 분산은 낮은 쪽과 연결된다. 교차검증은 데이터를 여러 조각으로 나눠 학습과 검증을 반복하면서 모델의 일반화 성능을 안정적으로 확인하는 절차다.

[예상 문제] 시험에서는 과대적합을 “복잡한 모델이라 항상 좋은 상태”처럼 바꾸거나, 과소적합을 단순히 데이터 수가 적어서 생기는 현상으로 축소하는 보기를 자주 낸다. 또 K-fold 교차검증을 훈련세트와 테스트세트를 한 번만 나누는 홀드아웃 방식과 섞어 출제하기도 한다. 핵심은 과대적합은 높은 분산, 과소적합은 높은 편향, 교차검증은 일반화 성능 확인이라는 연결 문장을 고정하는 것이다.

[심화] 편향과 분산은 trade-off 관계라서 모델이 복잡해질수록 편향은 줄기 쉽지만 분산은 커질 수 있다. 의사결정나무처럼 복잡도가 빠르게 높아지는 모델은 가지치기나 앙상블로 분산을 낮추고, 지나치게 단순한 모델은 변수 추가나 모형 구조 조정으로 편향을 완화한다. K-fold 교차검증은 데이터를 k개로 나눈 뒤 k-1개로 학습하고 나머지 1개로 검증하는 과정을 반복해 특정 분할에 따른 우연을 줄여 준다. ADsP에서는 공식보다 “왜 검증을 반복하는가”와 “어떤 상태가 편향/분산 문제인가”를 구별하는 문제가 자주 나온다.

[공부 순서] 1단계 과대적합·과소적합 정의를 편향과 분산 축으로 암기, 2단계 홀드아웃과 K-fold 교차검증 차이 정리, 3단계 가지치기·앙상블·변수조정이 어느 문제를 완화하는지 연결, 4단계 보기 문장에서 높은 편향/높은 분산 표현을 찾아 즉시 분류하는 연습.

[3단계 모델 비교] 의사결정나무는 CART=지니지수와 분산감소량, C4.5=엔트로피, CHAID=카이제곱과 F통계량으로 묶어 구분한다. K-means는 K 사전 지정, 이상치 민감, Elbow Method를 키워드로 잡고, DBSCAN은 K 불필요, 밀도 기반, 이상치 강건, Eps와 MinPts 설정을 함께 기억한다. 앙상블은 배깅과 랜덤포레스트가 병렬·복원추출·분산 감소 쪽이고, 부스팅은 이전 오분류에 가중치를 주는 직렬 학습이라는 대조로 정리한다.

[4단계 심화 예상문제] 보기에서 Accuracy와 Precision을 같은 뜻처럼 쓰면 오답일 가능성이 높다. p-value가 0.05보다 작으면 귀무가설을 기각한다. ARIMA(p,d,q)는 PACF가 p, ACF가 q, d가 차분 횟수다. R 회귀 출력 문제는 별표와 p-value로 유의 변수를 먼저 찾고, R-squared와 Adjusted R-squared를 구분한 뒤, 자유도에서 전체 표본 수를 역산하는 흐름으로 풀면 된다.

📋 주요 내용

이 연구를 쓴 이유는 공공조직의 조직목표가 민간조직보다 모호하고 측정하기 어렵기 때문에, 무엇이 조직목표 인식에 영향을 미치는지 확인할 필요가 있었기 때문이다. 저자는 특히 공무원 조직이 레드테이프, 무사안일주의, 복지부동과 같은 비판을 받아온 상황에서 조직목표의 명확한 설정이 공공조직 변화의 출발점이라고 보았다. 연구는 한국행정연구원의 「2018년 공직생활 실태조사」 자료를 활용했으며, 응답자는 공무원 4,000명이었다. 분석방법은 기술통계분석, 상관분석, 탐색적 요인분석, 다중회귀분석이며, 조직문화는 집단문화·혁신문화·위계문화·합리문화로 구분하고 업무전문성은 개인의 업무전문성 인식을 중심으로 측정했다. 기초통계에서 조직문화 평균은 집단문화 3.630, 혁신문화 3.260, 위계문화 3.348, 합리문화 3.484로 나타나 공무원들은 혁신문화보다 합리문화와 집단문화를 더 강하게 인식했다. 상관분석 결과 조직목표와의 상관계수는 집단문화 0.540, 혁신문화 0.520, 합리문화 0.502, 위계문화 0.428, 전체 업무전문성 0.403, 개인 업무전문성 0.324로 모두 유의미한 정(+)의 관계를 보였다. 다중회귀분석에서는 업무전문성 β=0.206, 집단문화 β=0.203, 혁신문화 β=0.195, 위계문화 β=0.136으로 조직목표에 유의미한 양(+)의 영향을 미쳤고, 주효과 모델의 조정 R²는 0.407로 나타났다. 저자가 전달하려는 핵심은 공공조직의 조직목표를 명확히 하기 위해서는 협력·신뢰·팀워크 중심의 집단문화를 강화하고, 동시에 개인 공무원의 업무전문성을 높이는 전략이 필요하다는 점이다.

[한계] 첫째, 개인의 업무전문성을 자기기입식 설문으로 측정했기 때문에 응답자의 주관적 편견이 반영되었을 가능성이 있다. 둘째, 통제변수가 성별, 연령, 근무기간, 직급 등 인구통계학적 변수에 한정되어 조직구조나 리더십 등 다른 영향요인을 충분히 통제하지 못했다. 셋째, 2018년 단일 시점의 자료를 활용했기 때문에 시간에 따른 조직문화와 조직목표 인식의 변화를 분석하지 못했다.
